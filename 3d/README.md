# 3D and CAD test files

Redistributable test files of the X-Ray.3D library (curiosity-ai/x-ray-others, `XRay.3D/dataset/`), one folder per format.
Only files with a stated, redistributable licence (CC0-1.0, MIT, CC-BY-4.0, public domain) are here; each folder has a `README.md` with the source,
licence and sha256 of every file, plus `LICENSE-MIT.txt` where MIT applies. `3d/manifest.json` is the machine-readable manifest (`file` is the
path in this repository, `datasetPath` the path in `XRay.3D/dataset/`); `3d/PATHS.md` maps one to the other.
