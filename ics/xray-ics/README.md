# X-Ray.Ics fixtures

Hand-written iCalendar (RFC 5545 / iTIP RFC 5546) and vCalendar 1.0 files made for the test suite of
X-Ray.Ics (`x-ray-others/XRay.Ics`). Each file isolates one tricky case; none is derived from a
third-party file or a real person's calendar (all names and addresses are made up, on `example.*`
domains).

- Source: generated by `XRay.Ics/tools/corpus/make_ics_fixtures.py` in curiosity-ai/x-ray-others; rerun
  it to rewrite them byte for byte.

Groups (file name prefixes):

| Prefix | Covers |
|---|---|
| `basic-`, `folded-`, `utf8-`, `mixed-line-endings` | the plain case, line folding (CRLF, LF, tab), non-ASCII text, CR / LF / CRLF mixed in one file |
| `encoding-` | UTF-8 BOM, UTF-16 LE/BE with and without BOM, Windows-1252 bytes, per-line `CHARSET` (Shift-JIS, Windows-1251) |
| `tzid-`, `floating-`, `all-day`, `duration` | `VTIMEZONE` rules, a custom zone that disagrees with IANA, IANA ids, Windows zone names, Mozilla-style ids, an unknown zone, floating times, all-day dates, `DURATION` |
| `rrule-` | FREQ from SECONDLY to YEARLY, INTERVAL, COUNT, UNTIL, BYDAY (with ordinals), BYMONTHDAY, BYMONTH, BYYEARDAY, BYWEEKNO, BYSETPOS, WKST, EXDATE, RDATE, DST crossings, all-day series, RECURRENCE-ID overrides and cancellations, invalid rules |
| `attendees-variety` | roles, PARTSTAT, RSVP, CUTYPE, quoted CN with commas, SENT-BY, delegation, non-mailto values with `EMAIL`, bare addresses |
| `attachment` | inline BASE64 (`FILENAME`, `X-FILENAME`, no name), URI references, `data:` URIs, damaged base64 |
| `text-escapes`, `param-quoting`, `x-properties`, `alarms` | TEXT escapes, quoted parameter values and RFC 6868 carets, X- and grouped properties, `VALARM` |
| `multi-event`, `two-calendars-concatenated` | several components of every kind, two `VCALENDAR` objects in one file |
| `method-` | iTIP `REQUEST`, `CANCEL`, `REPLY`, `COUNTER` |
| `outlook-`, `google-`, `apple-` | export shapes of the three big producers, written from their documented output, not copied |
| `vcalendar-1.0-` | VERSION 1.0 with quoted-printable (soft breaks, `CHARSET`), `TZ`, `DALARM`/`AALARM`, legacy `RRULE` |
| `malformed-` | truncation, missing or stray `END`, garbage lines, bad dates, no wrapper, unclosed quote, 500 levels of nesting, binary noise |
| `not-a-calendar` | input that is not a calendar at all (text, vCard, random bytes, empty) |
